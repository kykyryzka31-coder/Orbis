# Security and privacy

Orbis is designed as a local-first mapping application.

Do not commit provider API keys, access tokens, private map URLs, user PGD files, GPS traces, coordinates, or private project data to this repository.

Provider credentials must eventually be supplied through runtime configuration or protected build/runtime secrets, never hard-coded in source control.

PGD interoperability work must be independent and lawful: no copied proprietary code, DRM circumvention, encryption bypass, or stolen specifications.
